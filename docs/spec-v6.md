# v6 表面與接觸一致性

2026-10-29，使用者看過v5仍指出全校標線亂跑、人沉路、洞內飛草、騎車放手；已grill確認多處都有，並授權Implement the plan。保留真3D、角色美術、室內連通、事件與存檔；本機免費，不commit/push/deploy。

## 必做

1. 真地形三角面（含pad/carve）作為共用支撐面契約；普通道路與標線是精確貼合三角面覆材，人工樓層/坡道/洞底是獨立surface。referenceY/layer/連通性避免抓錯層，render/collision/nav/growable使用同版資料。
2. 路口拓撲與標線裁切，斑馬線貼坡；實際畫面新增確認金色導航Tube/CatmullRom會高空拉線，亦必須依有效路線及surface逐段顯示、無路不亂接。
3. 草根及整叢含風擺範圍只允許growable surface，排道路/人工板/洞體/手工地標；保留洞頂真土坡，載入/換層失效重建。
4. 角色支撐相位鞋底修正及高度平滑限制。男女專用騎姿，命名grip/saddle/crank/pedal接觸基準與受限IK；前後輪決定坡面pitch、踏頻依實際距離，停車/上下車姿勢正確，不以Sit/Idle冒充。

## 驗收門檻

- 全校有效道路法向支撐誤差<=2cm，人工接縫落差<=2cm；標線全在指定surface，無反折/重疊邊線/閃爍。
- 全部生成草叢非法根點與排除體積穿入0，根支撐距<=1cm。
- 靜止/著地支撐相位鞋底穿面<=2cm、離地<=3cm；擺動腳可離地但不可穿面。
- 男女騎乘穩態手至握把<=2cm、腳至踏板<=3cm、輪胎至路<=2cm；15/30/60FPS相同行程相位一致，轉場另驗。
- 代表平/長坡/彎/交叉/洞口內/門檻/多層的側面、低角度、多幀實際畫面；報最壞值與座標，不只平均/通關。
- 必要資料/導航重建、完整測試/build、主線/室內搜尋/雙向主要連通回歸。

## 實景發現的必修整合缺口

- DEM坡下仍有padBounds整矩形平板；必須精確裁切既有帶basement holes平面，只保留真正零高cell，不可只把QA起點抬到DEM來掩蓋。
- runtime對學生GLB有rotation.y=π，騎姿必須把此真wrapper及outline納入測試，不能依假想左右符號造成對側抓握。
- idle雙腳皆為支撐腳，真skin量測不能只取兩腳minimum；坡面曾有左腳離地7.6cm，需逐腳接地校正。walk支撐/擺動相位另判。
- 路線投影有真face/query數值，須分清楚路線離地和玩家站在錯層看線，保留原始失敗記錄。
