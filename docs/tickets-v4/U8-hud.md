# U8 精簡 HUD 與 Esc 選單

依賴：U4（輸入模式）、U6（集章冊）。規格：spec-v4 §10、§15.10；美術：art-direction-v4 §11。

- 常駐 ≤ 4 元件：任務卡、小地圖、小圖示列、互動提示；手機搖桿與動作鈕。
- Esc 選單：鳥瞰、第一人稱、鎖定、時段、搜尋教室、校園地圖、集章冊與成就、換角色、說明、回到起點。
- 彈窗佇列（置中卡片 1 ＋角落 toast 1；對話時暫停）。
- 更新 `walkthrough_qa.py`、`campus_visual_qa.py`、`walk_feel_qa.py` 的操作步驟。

驗收：遊戲中無重疊；手機 HUD ≤ 22% 畫面；所有 QA 工具通過。
