# 山海之間 · 中山校園導覽

國立中山大學的互動校園地圖＋可步行 3D 校園。首頁是依開放圖資與真實地形繪製的校園地圖；按「走進 3D 校園」或「開始導覽」進入 3D，跟著學姊阿灣完成六章「新生導覽」：校門報到 → 西子灣隧道 → 行政大樓 → 圖資大樓 → 理工長廊進室內找 SC2001 → 海堤看夕陽。

- 理工八棟（SC、EN、BI、PH、CH、EC、MS、EV，60 層、872 個室內空間）可走進室內，含樓梯、電梯與跨棟走廊。
- 11 處地標依實景照片以 Blender 手工建模（行政大樓、圖資大樓、文學院、西子灣隧道、校門校碑、海堤、逸仙館、體育館、海科院、活動中心、沙灘會館）；其餘建築依 OpenStreetMap 輪廓生成。
- 地形為內政部 20 m 數值地形模型（壽山、海岸、西子灣）。
- v4：Blender 自製的卡通大學生主角（男／女、6 組配色、暱稱）；20 位可搭話的師生、店員、警衛、志工與獼猴，分支對話以視覺小說式對話框呈現；集章、成就、拍照模式；三個小遊戲（海堤夕照、獼猴小偷追逐、校史問答）；依時段變化的 NPC 作息與校園事件；校門租腳踏車、章節間搭校園公車直達；葉片卡樹冠、草叢、依地形水深的海面、雲層與立面變化。

## 理學院室內配置

理學院 75 間有房號的房間提供依用途設計的家具；SC2002-4 已擴大約 41%，設有ㄇ字型沙發、貓咪老師玩偶、壁掛電視、茶几、織紋地毯、辦公桌與書櫃；SC2002／SC3002 辦公室群及 SC4010 系辦有桌燈、文件、植栽與掛畫。SC2004 為電腦教室，四樓 SC4010 為應數系系辦、SC4009 為數學圖書館。SC1005／SC1001／SC2001／SC3001 採可步行的階梯排座，分別為 112／56／76／59 席。家具具有碰撞，可走入參觀與拍照；尚未提供入座或操作電腦功能。家具安排為導覽示意，不是實景座位數或室內配置的測量紀錄。

## v10.2 十三條支線全面最佳化

- **不再白跑**：六條支線改了委託人、收尾人或地點，每條在可接的時段內，最長一段都在 52 公尺內。例如迎新傳單改由洞口的小橘代轉（從 477 m 降到 27 m）、洞口攝影從 484 m 降到 10 m、Mia 的第一天從 268 m 降到 29 m、海風小舞台改由長廊的 Mia 收尾（從 407 m 降到 18 m）。報到清單保留一段行政大樓到圖資大樓的導覽路線。
- **時段不對會告訴你**：靠近委託人時，時段不對的支線會顯示成灰色的「接取・○○（可接：夕陽，按 N）」，不能誤接；頭頂圓徽與目標卡也會說明何時再來。已接取的支線不受影響。
- **選擇有後果**：每條支線最後的兩個選項，會在世界裡留下看得到的成果，例如公告板的認領告示、花盆的排法、攤位招牌、洞口展示板。相關人物下次見到你會提起你的選擇；Mia 會坐到你推薦的位子。
- **收藏品**：完成每條支線會得到一件收藏品（例如失物保管回條、壽山洞構圖卡、開場曲目卡），依你的選擇有兩種版本，放在收集冊的「支線」分區。
- **接著做下一條**：完成時會提示附近適合接著做的支線，例如隧道兩條、圖書館一串、長廊白天一串、傍晚的海堤兩條。
- 舊存檔照常可用：進行中的支線依步驟 ID 對位；已完成的支線保持完成，並補發收藏品。

## v10.1 夕陽與夜唱活動、手機奔跑、減少卡頓

- **海堤夕陽人潮**：傍晚走到海堤，阿文會邀你到蘿蔔坑旁的座位坐下，面向大海安靜看一分鐘夕陽（移動會重新計時）。G 會帶你到座位，完成後解鎖成就「一分鐘」。
- **長廊夜唱**：夜晚在理工長廊，允哲會邀你坐在柱廊旁聽他彈吉他。光圈縮到最小時按 E（手機按畫面下方的「拍手」）跟著拍手，8 拍中拍到 5 拍就解鎖成就「聽眾」；沒拍滿也能聽完，下個夜晚可以再試。吉他旋律由程式即時合成，關掉音樂仍可看光圈拍手；拍點以按下的瞬間判定，低幀率裝置也準。
- **手機奔跑**：一進場就看得到「跑」按鈕；搖桿推到外圈會自動奔跑，外環亮起；按「跑」可以切換成持續奔跑。
- **減少突然頓一下**：卡頓主要來自材質第一次出現時，畫面要等著色器編譯完才能繼續。現在載入畫面期間會先把所有材質編譯並畫過一次，走動時不再臨時編譯。

## v10 支線動線、看得見的互動、校園事件與有來源的故事

這一版的改進由 Gemini 3.8 Flash、Fable、Astra 三方兩輪討論後定案，協調者整合，並由 Fable、Astra 分工實作。

- **互動清單**：同一處有兩件以上可做的事時，畫面上直接列出清單（例如「小禾 · 3 件事」），E 執行高亮項，1–4 直接選，R 移動高亮，手機可直接點；方向鍵永遠用來走路。高亮跟著最重要的事走（追蹤中的支線優先），不會被先進入範圍的地標卡住。NPC 頭上的金色「！」表示有支線可接，藍色「？」表示可交付。
- **支線動線**：失物招領、迎新傳單、報到清單、海風小舞台、Mia 的第一天、高中人才培育班六條改寫，最後一步發生在新的人或物件旁（例如警衛室旁的失物登記簿、洞口的迎新收件箱、四樓的心得留言板），不再為了回報跑回起點。舊存檔依步驟 ID 對位，進度不會錯位。
- **校園事件**：五個事件改在實際發生的地點觸發，並寫進手帳。白天的獼猴警戒可以參加：阿滿姐邀請你把點心收進包包、退開讓路，大膽沿步道走過後自己回到邊坡；行為依學校的獼猴相處守則（不外露食物、不餵食、不接觸、不攻擊），拒絕不會受罰。
- **門牌**：門牌依門洞平面朝向公共走廊，並貼在實際牆面上；SC2001 等理學院 38 塊原本歪斜的門牌已修正。
- **故事與傳說**：故事卡依來源分成「校史」「新聞記載」「校園趣聞」三種標籤，每則附來源連結；新增防空洞裡的《昭和二十》、獼猴搶食補償試辦、余光中任文學院院長與兩則獼猴新聞趣聞，並修正舊卡中查不到出處的說法。九位 NPC 會主動講一則故事。怪談類傳說查無可引用的來源，暫不收錄。

## v9 主線支線切換與校園更正

## v6 接地、騎乘與校園手帳

v6 修正道路／標線與地形不同高、坡下隱形平板、洞內植被、導航線、騎姿握把／踏板及坡面鞋底；導航已依新版表面重建。

按 **J** 或 Esc 選單開啟校園手帳：接受／追蹤 13 條支線；Q 或目標卡切換主線與支線，查看事件經過與人物見聞；G 前往目前追蹤目標，靠近按 E 互動；重疊目標會列成清單，E 執行高亮項、1–4 直接選、R 移動高亮，手機可直接點。拍照任務需用 P 開啟相機、Space 真正拍照，快門當刻須符合任務地點與時段。任務、選擇與紀念章保存在本機瀏覽器。

六類隨機偶遇包含猴子搶點心、偷帽子、風吹傳單、滾球、臨時合奏與合照。可參與或放棄；猴子只搶事件專用物品，不扣既有收藏。偶遇不在主線對話、手帳、遊戲或自動帶路期間插入。

重開主線保留收藏和手帳；清除全部進度另需確認。

地標可從首頁搜尋「校碑」或「行政大樓」，進入 3D 後可用資訊卡「查看全貌」辨識完整模型。隧道到達時會面向入口，可沿洞內通道走至另一端。

## 本機執行

需要 Node.js 22.12 以上（本機以 Node 24 驗證）。

```sh
npm ci
npm run dev        # 開啟終端機顯示的網址
npm test           # vitest（含 878 房實走驗收，約 2 分鐘）
npm run build      # 資料完整性、步行資料、故事資料、tsc、Vite
```

瀏覽網站不需 API key、帳號或付費服務；圖資、字型（Noto Sans TC 子集，OFL）、校徽均由本機提供。`?quality=A|B|C` 可強制畫質等級（預設依裝置自動並在掉幀時降級）。

## 限制與已知差異

- 全部效能數字來自 SwiftShader 軟體渲染，非真機 GPU 認證。
- 官方校園平面圖為示意插畫（對位 LOO RMS 47.7 m），建築位置以 OSM 為準；校門位置採平面圖對位（±40 m），與 OSM「校門」節點相差約 140 m，待現地確認。
- 理工八棟的室內樓層高度沿用平地假設；電資大樓實際在坡上（約 +24 m），旁邊山坡因此較陡。
